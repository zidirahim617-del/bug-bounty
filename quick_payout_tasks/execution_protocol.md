# Algora / Polar Quick Payout Execution Protocol (4-7 Days)

## Step 1: Issue Selection
- Pick issues with active Algora escrow labels (`bounty`, `funded`).
- Prefer small bug fixes, missing error handling, or test coverage additions.

## Step 2: Local Verification
- Run `cargo test` or test suite to ensure 100% green CI before submitting.

## Step 3: PR Submission & Claiming
- Submit clean, well-documented PR referencing the issue number.
- Comment on the Algora/Polar escrow interface to claim the bounty upon merge.
- Typical payout window: **4 to 7 days** post-merge.
